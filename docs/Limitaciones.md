# Limitaciones del Proyecto

## Limitaciones Técnicas

- El sistema depende de la disponibilidad de señal GSM en el gateway.
- La precisión de ubicación depende de la recepción GPS.
- El sistema está diseñado para monitoreo y no para control del ganado.
- La cobertura LoRa puede verse afectada por obstáculos geográficos.

## Limitaciones Operativas

- El sistema no garantiza la prevención de robos.
- No sustituye la inspección física realizada por el ganadero.
- El monitoreo inicial se limita a aproximadamente 10 animales.

## Limitaciones Económicas

- El costo aumenta al incrementar el número de animales monitoreados.
- Cada nodo requiere componentes electrónicos y alimentación propia.

## Limitaciones del Alcance Académico

- No se desarrollará inteligencia artificial para predicción de enfermedades.
- No se implementará comunicación satelital.
- No se desarrollará una aplicación comercial completa.
